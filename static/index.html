Cómo funciona

Un único worker captura la cámara, detecta rostros con el clasificador Haar y clasifica género y rango de edad cada 5 frames. El vídeo llega por MJPEG a todos los clientes sin duplicar la inferencia.

API GET /api/status GET /api/config POST /api/snapshot

Esta aplicación procesa rostros localmente en la Arduino UNO Q. No se guardan imágenes a menos que actives el snapshot.
